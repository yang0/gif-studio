# gif-studio：剪辑导演与整片节奏规范

本文件参考 Remotion Skills 的独立时间线/剪辑原则，以及 MoneyPrinterTurbo 的音频、素材、字幕预览式生产；我们只借鉴工作流，不引入它们作为强制渲染依赖。

## 最重要的改变

以前：每句口播自动对应一张 GIF → 拉伸/保持到镜头时长 → 顺序拼接。

现在：**整篇口播与真实配音先锁定 → 视觉事件 → GPT GIF 镜头挑选 → 帧级剪辑表 → 预览整片 → 根据具体问题局部重做。**

## 编辑不是补帧

- 每个镜头必须有“为什么在这里剪”的叙事解释 cut_reason；“时间到了”不算。
- 镜头可以在一句话中间切换；切点是信息被揭示、动作完成或问题转折的位置。
- 同一句话可以有多个视觉镜头，也可以让一个视觉镜头跨过两句口播。
- 不要为填时长而长期停在 GIF 最后一帧；默认冻结不得超过该镜时长的 25%。
- GIF 原始动作不足以覆盖内容时优先：修改分镜、生成新的独立 GPT GIF 镜头、调整真实旁白节奏；不自动循环或机械放慢到不自然。
- 禁止单一“大标题 + 中间小 GIF + 底部标签”的全片套版。
- 不允许使用矢量动画替代 GPT GIF。字幕和精确数字可后期叠加。

## 先声音、后剪辑

真实配音必须由用户提供，或从当前环境明确可用且获得许可的 TTS 产生。首先测量配音时长，再根据停顿、句意和动作阶段写 shot duration。音画差值超过 0.35 秒就需要重新编辑；不能默认裁掉长音频或在短音频后补静音，冒充同步。字幕需相应真实时间戳；没有真实对齐信息时不要称为词级同步。

## 先审一次完整视频，而非只有单镜审核

预览时检查：
1. 开头 3 秒是否出现明确的主问题或异常变化。
2. 每个动作与口播同期，而不是口播讲到下一层画面仍停在前一层。
3. 画面构图有自然的景别/视觉规模变化，不是固定小图窗口。
4. 镜头衔接是否保留观众需要记住的线索，避免突然切成无关风格。
5. 末尾是否把开头问题回答清楚。
6. 无效长定格、循环接缝、素材重复与字幕遮挡是否出现。

视觉上是否好看/是否表达正确必须实际观看成片，脚本只负责防止可量化的失败。

## edit-plan.json

先使用 scripts/edit_plan.py 由实际 GIF + storyboard + 配音时长生成 draft。
导演需要逐条填写 cut_reason、整片 review_notes 并将 review_status 设为 approved；最后执行 --verify 检查。
仅修改 review_status 不等于真实审核。没有真实 GIF、配音和整片审查时不得声称交付正式知识口播视频。

正式合成默认强制要求编辑计划审核与真实音频。确实需要无声视觉 B-roll 时只允许 --allow-silent-preview，交付报告明确标注预览。
