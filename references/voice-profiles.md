# 口播声线配置

用户给定声线优先于任何默认。可选表达方式：
- 清晰科普：从问题到机制，再用案例与边界收尾。
- 朋友聊天：具体、自然、接续上一个人的疑问。
- 调查纪录片：事实与证据推进，克制悬念。
- 个人评论：有观点，也交代例外和成立条件。
- 教程讲解：围绕完成一个操作目标逐步展开。

用户可以提供认可的示范段落。提炼语气、词汇与节奏，但不逐字模仿或复制他人作品。
建议项目保存 voice-profile.md：目标受众、语言风格、术语比例、禁用口头禅、讲述者人设、适用时长。
不要把视觉风格（cinematic / pixel-art / watercolor）自动映射为口播人设。
