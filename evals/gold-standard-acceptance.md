# gif-studio 首条金标准视频验收卡（尚未完成真实样片）

目标：从头完整交付 15–20 秒主题为“为什么手机通知会打断专注”的知识短片，不能用造假 QA 或虚假素材满足以下条件。

## 内容与配音

- [ ] 完整口播被审核、确认，逻辑自然，不是平行的知识点列表。
- [ ] 有实际可听的完整旁白音轨；若没有，产品状态明确为 silent preview。
- [ ] 镜头长度由真实朗读或明确句级时间戳决定，没有强迫所有镜头等长。

## 视觉导演

- [ ] 至少 3 个彼此不同的知识视觉事件：专注持续、通知打断、回到任务的认知代价。
- [ ] 每镜都写明视觉证据、开头/变化/结尾、构图，以及与上一镜/下一镜的联系。
- [ ] 主体占据有效视觉空间，不是顶部大标题+中间小窗口+底部标签的套版 PPT。
- [ ] 任意两个镜头对换后，信息逻辑应明显受损；如果可以随意交换，导演方案不合格。

## 真实素材

- [ ] 新镜头分别生成真实 GIF，并登记各自实际来源、完整 prompt 和文件 SHA。
- [ ] 未声明的同一 GIF 复用为多个不同分镜，应被 production_preflight 阻止。
- [ ] 不合语义的图像（如 GPS 镜头出现“电脑+灯泡”）直接退回，不以“相关”作为合格借口。
- [ ] 每镜都有真实接触表、语义/运动/风格/构图四项可复查审核。

## 成片

- [ ] SRT 的字幕与实际口播时间大致同步；不能把无声字幕预览称为完成的口播视频。
- [ ] 分镜顺序、屏幕重点、画面变化能跟随解释发展。
- [ ] 通过现场观看最终 MP4 及 ffprobe 编解码检查，复核 9:16、H.264、持续时长。
- [ ] 交付最终视频、独立 GIF、完整口播、导演计划、来源记录及质量报告。
- [ ] 将通过审查的真实视频演示放到 README（可嵌入或外链），并明确来源及限制。

**注意**：目前此表是验收目标，不代表已有真实 GPT GIF 成功样片。
